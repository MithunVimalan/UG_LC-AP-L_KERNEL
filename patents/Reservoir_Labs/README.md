# Reservoir Labs (R-Stream polyhedral compiler) — portfolio now held by Qualcomm

Reservoir Labs' compiler patents were assigned Reservoir Labs -> Significs and Elements, LLC -> Qualcomm Technologies, Inc. -> Qualcomm Incorporated (per Google Patents assignment records on US10789055B2, US9830133B1 and others).

The full entries are in [`../Qualcomm/README.md`](../Qualcomm/README.md), sections 3.2 and 3.6-3.12:

| Number | Title | F |
|---|---|---|
| US8661422B2 | Methods and apparatus for local memory compaction | F3 |
| US10789055B2; US11537373B2 | Systems and methods for scalable hierarchical polyhedral compilation | F1 + F2 |
| US8572595B1 | Methods and apparatus for aggressive scheduling in source code compilation | F1 |
| US10180828B2 | Systems and methods for power optimization of processors (JPLCVD affine scheduling) | F1 + F3 |
| US8930926 | polyhedral parallelizer and locality optimizer | F1 |
| US9830133B1; US11200035 | Automatic communication optimizations in a compiler based on a polyhedral representation | F2 |
| US10698669; US11500621 | Methods and apparatus for data transfer optimization | F2 |
| US10496304; US11068178B2 | Systems and methods for minimizing communications | F1 + F2 |

Why this portfolio matters: the polyhedral model separates **schedule**, **access relation** and **data layout** into three maps — the same split as your loop counters -> (1) -> (2) -> (3) chain. Several of these patents are listed as expired (fee-related) on Google Patents; confirm status on USPTO.
